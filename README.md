# Театр чудес

Предварительная главная страница по утверждённому макету `design/homepage.svg` (MacBook - 1.svg).

## Запуск

```sh
python3 -m http.server 3000 --directory dist
```

Откройте `http://localhost:3000`. Установка зависимостей и сборка не требуются.

## Файлы

- `dist/index.html` — семантическая главная страница.
- `dist/styles.css` — адаптивная сетка, палитра, анимации и режим уменьшенного движения.
- `dist/app.js` — поля бюджета, диалоги и просмотр фотографий.
- `dist/programs.js` — отдельный слой данных программ и тарифов для будущих страниц.
- `dist/assets/` — графика из авторского макета, фотографии и локальные шрифты с лицензиями.
- `design/homepage.svg` — последний утверждённый оригинал.

Шрифты: PT Serif для текста/кнопок и Cormorant Infant для заголовков; заголовки сжаты по горизонтали, чтобы повторить вытянутую типографику макета.

## Что работает

Настройка бюджета, даты, возраста (включая взрослых) и количества гостей; увеличение фотографий; модальные окна акций; навигация по секциям. Выдача подборки отключена по макету. Категории пока не ведут на страницы — они будут подключены отдельно. Анимации отключаются при `prefers-reduced-motion: reduce`. Все ресурсы локальные: внешних аналитических скриптов, cookies и трекеров нет.

Цены предварительные: шоу — по переданной сетке декабря 2026/января 2027, мастер-классы — для групп до 10 и до 20 человек. Для других дат и больших групп нужен индивидуальный расчёт. Для 31 декабря показывается только дневной тариф 09:00–18:00; вечер и ночь отмечены отдельно. Выезд за МКАД и площадка не включены в автоматически показанную сумму. Возрастные ограничения в демонстрационной подборке ориентировочные и требуют согласования перед запуском.

## Что подключить перед приёмом заявок

Контакты и канал отправки заявки пока не предоставлены, поэтому сайт не имитирует отправку формы. Видео и полное портфолио пока обозначены как будущие разделы. Тексты скидок перенесены из макета; окончательные условия и их суммирование следует согласовать. В дальнейшем можно добавить страницы категорий, карточки программ, полноценный калькулятор сборной программы и backend для заявок.

## Проверка

```sh
npm run check
```

Для публикации достаточно любого статического хостинга с корнем `dist`. Для GitHub Pages можно загрузить содержимое `dist` в корень публикуемой ветки; либо настроить Pages workflow, публикующий папку `dist`.

## Публикация

GitHub Pages публикует папку `docs` из ветки `main`. Она должна совпадать с `dist` при каждом изменении страницы.
