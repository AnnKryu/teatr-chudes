# Театр чудес

Главная страница и каталог программ по утверждённым SVG-макетам. Главная соответствует `design/homepage.svg` (MacBook - 1.svg).

## Запуск

```sh
python3 -m http.server 3000 --directory dist
```

Откройте `http://localhost:3000`. Установка зависимостей и сборка не требуются.

## Файлы

- `dist/index.html` — семантическая главная страница.
- `dist/styles.css` — адаптивная сетка, палитра, анимации и режим уменьшенного движения.
- `dist/app.js` — поля бюджета и диалоги акций.
- `dist/programs.html`, `dist/catalog.css`, `dist/catalog.js` — четыре вкладки каталога, 18 программ и окна с подробностями.
- `dist/programs.js` — отдельный слой данных программ и тарифов для будущих страниц.
- `dist/assets/` — графика из авторского макета, фотографии и локальные шрифты с лицензиями.
- `design/homepage.svg` — последний утверждённый оригинал.

Шрифты: PT Serif для текста/кнопок и Cormorant Infant для заголовков; заголовки сжаты по горизонтали, чтобы повторить вытянутую типографику макета.

## Что работает

Настройка бюджета, даты, возраста и количества гостей; диалоги акций; плавное приближение фото. «Программы» открывают `programs.html` с анимацией по умолчанию. Карточки главной ведут сразу в соответствующий раздел: `?category=animation`, `show`, `workshop` или `quiz`. Переключение вкладок сохраняет URL и поддерживает браузерную историю; клавиатура: стрелки, Home и End. Кнопки «Подробнее» открывают фото, описание, длительность и состав. Все 18 программ перенесены из четырёх авторских макетов от 29 октября 2026 года; цены в каталоге не указаны.

Анимации отключаются при `prefers-reduced-motion: reduce`. Графика, фото и шрифты локальные; внешней аналитики и трекеров нет.

## Что подключить перед приёмом заявок

Контакты и канал отправки заявки пока не предоставлены, поэтому сайт не имитирует отправку формы. Видео и полное портфолио пока обозначены как будущие разделы. Тексты скидок перенесены из макета; окончательные условия и их суммирование следует согласовать. В дальнейшем можно добавить отдельные подробные страницы программ, полноценный калькулятор комбо и backend для заявок.

## Проверка

```sh
npm run check
```

Для публикации достаточно любого статического хостинга с корнем `dist`. Для GitHub Pages можно загрузить содержимое `dist` в корень публикуемой ветки; либо настроить Pages workflow, публикующий папку `dist`.

## Публикация

GitHub Pages публикует папку `docs` из ветки `main`. Она должна совпадать с `dist` при каждом изменении страницы.
